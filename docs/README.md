# Preza_denis — документация

Облегчённый SDD: сначала документация, потом код. У каждого модуля своя папка `docs/modules/NN-name/` с двумя файлами:

- `analysis.md` — анализ и спецификация до кода: что берём из Figma, токены, структура, адаптив, риски, критерии готовности.
- `implementation.md` — реализация после кода, без привязки к языку и фреймворку: как модуль работает и какая в нём бизнес-логика, отклонения от анализа, проверка. Ссылки на файлы только в конце, в разделе «Файлы», для навигации.

Шаблоны: `docs/modules/_template/`.

## Общий анализ и риски

- Hero собран абсолютным позиционированием, буквы размером 200–600px. На мобильных его нужно перекомпоновать, иначе будет горизонтальный скролл.
- Наклонные декоративные линии выходят за пределы фрейма. Нужен `overflow-hidden` на секциях.
- В секциях 7, 8 и 10 нет контента, только номера. Вероятно, туда позже добавят плееры или ссылки.
- Ссылок на музыку в макете нет.
- Опечатка в макете: «логотопи» вместо «логотипи». Уточнить у пользователя.
