# 03 — Covers: анализ

Статус: утверждён
Figma: фрейм `1:2`, плашка `1:116` (y 1846–2682), карточки `4:11…4:45`, заголовок `4:48`, подпись `4:66`, стрелка `53:25`, линии `53:14…53:24`

## Цель

Секция «Клікай на обкладинки — слухай музику!»: шесть карточек с обложками работ, под каждой кнопка «Процес роботи», рукописная стрелка с подписью и декоративные наклонные линии.

## Дизайн

- Плашка на всю ширину страницы, фон `#171717` (токен surface), высота 836 на десктопе.
- Заголовок 30px Bold uppercase, белый, ширина до 350px (три строки), отступ сверху 172px.
- 6 карточек в один ряд по 1460px (x 70–1530), ширина карточки около 225, зазор 22. Карточка `#414141` (card-cover), радиус 10, высота 273.
- В карточке: квадратная обложка ~177×175 (отступ 25 по бокам, 22 сверху), название 20px Bold uppercase (отступ 11 от обложки), исполнитель 20px Regular uppercase (через ~5px).
- Кнопка «Процес роботи» под карточкой через 34px, ширина как у карточки, высота 40, акцент `#ffa028`, радиус 5, текст 15px Bold uppercase.
- Стрелка (ScribbleArrow, 330×100) и подпись «Натисни, щоб побачити творчий процес» (20px Regular, `#ffa028`, по правому краю, три строки) внизу справа. Стрелка зеркальная, остриё смотрит влево вверх на кнопки.
- Восемь наклонных линий (шаг 47px, `#ffa028` с прозрачностью 0.21, толщина 2) идут из правого верха в левый низ через весь блок карточек, на фоне.
- Тексты: заголовок «Клікай на обкладинки — слухай музику!». Карточки (название / исполнитель): «Я знаю / TAYA», «Чому / TAYA», «Шукай / DOROTIUK», «Як добре / Kreshtofova», «Дуда / Thesaurum», «З Днем Народ.. / ZHANNET». Пробелы в конце строк обрезаются.
- Ассеты: `imgImage1.webp` (1280×720, кадрируется), `imgImage2.webp` (1280×720, кадрируется), `imgImage5.webp` (600), `imgImage6.webp` (1900, тяжёлый), `imgImage7.webp`, `imgImage8.webp`; стрелка `imgGroup14.svg`; линия `imgVector19.svg` (повторяется как inline-SVG).

## Структура

- `src/components/sections/Covers.tsx` — секция, данные `COVERS` (title, artist, image, опциональный crop).
- `src/components/sections/covers/CoverCard.tsx`, `DecorLines.tsx`.
- `src/components/ui/ScribbleArrow.tsx` — общая рукописная стрелка (src, размеры, зеркальность, className).
- Переиспользуются `Section`, `SectionTitle`, `ProcessButton`.
- Все картинки через `next/image` с `sizes`, чтобы тяжёлые файлы не отдавались целиком.

## Адаптив

- Десктоп (≥1280): 6 колонок, как в макете. Шрифт карточки и отступы слегка сжимаются между 1280 и 1600; длинное название обрезается многоточием.
- Планшет (768–1279): 3 колонки, подпись со стрелкой справа внизу.
- Мобильный (<768): 2 колонки, шрифт меньше, стрелка уменьшается, линии масштабируются по ширине вместе с пропорциями.
- Горизонтального скролла нет на 320–2560, плашка тянется на всю ширину, содержимое до 1600.

## Поведение

- Клик по карточке обложки и по «Процес роботи» — заглушки (`type="button"`, без действия).
- Hover: небольшое снижение прозрачности. Focus-visible: акцентное кольцо (глобальное).
- Alt обложки: «Название — исполнитель». Стрелка и линии декоративные, `alt=""` / `aria-hidden`.

## Риски и edge cases

- Тяжёлый `imgImage6.webp` (7.8 МБ): только `next/image` с `sizes`.
- Макетная ширина карточек 222/227 колеблется, берём единую.
- Название «З Днем Народ..» с точками — как в макете.
- Подпись и стрелка перекрываются на 14px, как в макете.

## Критерии готовности
