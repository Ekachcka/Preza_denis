# 00 — Foundation: реализация

Статус: готово

## Что сделано

Сайт открывается на одном тёмном экране с шрифтом Montserrat (латиница и кириллица). Страница состоит из 12 пустых секций в порядке макета, каждая с якорным идентификатором: hero, about, covers, arrangements, album, stock-strip, ads-music, logos, samples-strip, cover-songs, why-me, contacts.

## Поведение

- Язык страницы: украинский. Заголовок вкладки: «Денис Булах — гітарист, аранжувальник, звукозапис».
- Фон страницы `#0b0b0b`, текст белый, акцентный цвет `#ffa028`.
- Горизонтального скролла нет на ширинах 320, 768, 1600 и 2560.
- Секция ограничивает содержимое шириной 1600 и центрирует его; боковые отступы 16 / 40 / 70 по размеру экрана.
- Заголовок секции: 30px Bold, заглавными, на узких экранах уменьшается до 20px.
- При навигации с клавиатуры выбранный элемент подсвечивается акцентным кольцом.

## Отклонения от анализа

- Цвета взяты из Figma, а не из прежних значений в docs.
- Для тестов поднят `@types/node` до ^22 (требование Vitest).
- Субагенты `reviewer` и `adversarial-reviewer` в этой сессии были недоступны, ревью заменено проверкой автотестами и самопроверкой.
