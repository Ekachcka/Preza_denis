# 00 — Foundation: анализ

Статус: утверждён
Figma: фрейм `1:2` (1600×9809), fileKey `FIGMA_FILE_KEY`

## Цель

Заложить основу сайта: шрифт Montserrat, токены Tailwind, корневой layout с метаданными, каркас страницы из 12 секций, общие обёртки и тестовый стек.

## Дизайн

Токены берутся из Figma (они приоритетнее прежних значений в docs):

| Токен | Значение | Где |
|---|---|---|
| plate | `#0b0b0b` | плашки 6, 9, контакты; предположительно фон страницы и Hero |
| surface | `#171717` | плашка секции обложек, огромные буквы Hero |
| card-cover | `#414141` | карточки обложек |
| card | `#2e2e2e` | карточки 7, 8, 10, 11 |
| accent | `#ffa028` | кнопки, «Тицяй і слухай», контакты |
| accent-num | `#ff8e00` | крупные номера карточек |
| muted | `#4c4c4c` | заголовок «контакти Для співпраці» |
| text | `#ffffff` | основной текст |

Шрифт: Montserrat (вариативный, subsets latin + cyrillic), веса 400, 500, 700, 800, 900. Скругления: карточки 10px, кнопки 5px.

Заголовок секции: 30px, Bold, uppercase.

## Структура

- `layout.tsx`: Montserrat через `next/font/google`, `lang="uk"`, metadata (title «Денис Булах — гітарист, аранжувальник, звукозапис»).
- `globals.css`: `@theme` с токенами, тёмная тема, без шаблонного кода.
- `page.tsx`: `main` с 12 секциями-заглушками в порядке Y из Figma, у каждой `id`.
- `components/ui/Section.tsx` (обёртка с `overflow-x-clip` и контейнером 1460), `SectionTitle.tsx`.
- Остальные общие компоненты создаются при первом использовании в модулях.
- Тестовый стек: Vitest + RTL + jsdom, Playwright (Chromium), скрипты `test`, `test:e2e`, `typecheck`.
- Шаблонные ассеты `public/*.svg` удаляются.

## Адаптив

Контейнер 1460 с отступами 70 на десктопе (центрируется выше 1600), 32–40 на планшете, 16–20 на мобильном. Заголовки `clamp(20px, 5vw, 30px)`. Схема по секциям (принята пользователем): планшет — обложки в 3 колонки, карточки 3/2 колонки, About в одну колонку; мобильный — 1–2 колонки, Hero пересобирается, наклонные линии уменьшаются.

## Поведение

Одна страница без навигации. Фокус: `focus-visible` кольцо акцентного цвета; hover лёгкий. Горизонтального скролла нет.

## Риски и edge cases

- Hero на абсолютных позициях ломается на узких экранах — решается в модуле Hero.
- Тяжёлые изображения только через `next/image`.
- Vitest не умеет `next/font` и `next/image` — моки.
