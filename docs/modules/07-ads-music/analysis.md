# 07 — Музыка для рекламы: анализ

Статус: утверждён
Figma: фрейм `1:2`, node `2001:13`, fileKey `FIGMA_FILE_KEY`

## Цель

Показать заголовок и девять пронумерованных карточек музыки для рекламы, блогов и медиа проектов.

## Дизайн

Заголовок 30px Bold uppercase; карточки #2e2e2e, скругление 10, номера 50px #ff8e00; ряд из 5 и ряд из 4 по центру; наклонные линии на фоне; стрелка «Тицяй і слухай».

## Структура

Секция AdsMusic, ScribbleArrow, блок наклонных линий.

## Адаптив

- Десктоп (≥1280): композиция макета 1600.
- Планшет: 3 колонки.
- Мобильный: 2 колонки, линии уменьшены.

## Поведение

Кнопки и карточки без ссылок (заглушки по решению проекта). Минимальный hover (прозрачность) и focus-visible кольцо.

## Риски и edge cases

- Макет на абсолютных позициях, переводится во flex/grid.
- Горизонтального скролла нет на 320–2560.

## Критерии готовности

- [ ] Визуально совпадает с Figma на 1600.
- [ ] Нет горизонтального скролла на 320–2560.
- [ ] Unit-тесты на рендер и тексты.

## Открытые вопросы

Нет: решения по адаптиву, hover/focus и alt приняты пользователем.
