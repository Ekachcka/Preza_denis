# 07 — Музыка для рекламы: реализация

Статус: готово

## Что сделано

Заголовок «Музика для реклами, блогів і медіа проектів», девять пронумерованных пустых карточек (как в макете), наклонные декоративные линии на фоне и рукописная стрелка с подписью «Тицяй і слухай».

## Поведение

- Карточки содержат только номер 01–09, интерактива нет.
- Десктоп: 5 карточек в первом ряду, 4 по центру во втором. Планшет: 3 колонки. Мобильный: 2 колонки, линии уменьшаются.
- На экранах шире 1600 линии заканчиваются у правого края центрального блока.

## Отклонения от анализа

Вертикальные отступы секции 236px сверху и снизу на десктопе. Рядом с секциями, у которых тоже есть свои отступы, зазор может быть больше макета (страница выходит на 9954px вместо 9809px).

## Проверка

Typecheck, lint, unit проходят; визуально сверено на 1600; горизонтального скролла нет на 320–2560.
