# 12 — Контакти: анализ

Статус: утверждён
Figma: фрейм `1:2`, node `2001:18`, fileKey `FIGMA_FILE_KEY`

## Цель

Контакты для сотрудничества: телефон, email, Instagram.

## Дизайн

Тёмная плашка #0b0b0b, серый заголовок #4c4c4c, три иконки с оранжевым текстом 20px Medium, рукописные стрелки.

## Структура

Секция Contacts; ссылки tel:, mailto:, https://instagram.com/bulakh_denis.

## Адаптив

- Десктоп (≥1280): композиция макета 1600.
- Планшет: как десктоп.
- Мобильный: столбец; стрелка скрыта на экранах уже 1280.

## Поведение

Кнопки и карточки без ссылок (заглушки по решению проекта). Минимальный hover (прозрачность) и focus-visible кольцо.

## Риски и edge cases

- Макет на абсолютных позициях, переводится во flex/grid.
- Горизонтального скролла нет на 320–2560.

## Критерии готовности

- [ ] Визуально совпадает с Figma на 1600.
- [ ] Нет горизонтального скролла на 320–2560.
- [ ] Unit-тесты на рендер и тексты.

## Открытые вопросы

Нет: решения по адаптиву, hover/focus и alt приняты пользователем.
