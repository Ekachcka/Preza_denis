## Цель

Подключить реальные mp3 (папка `Data/`) к карточкам страницы: на карточке мини-плеер с play/pause и прогрессом. Заменить заглушки картинок на присланные.

## Решения пользователя

- Плеер: карточка + мини-плеер с прогрессом (play/pause, полоса прогресса с перемоткой, время).
- Одновременно играет один трек: запуск нового ставит предыдущий на паузу.
- Названия треков сопоставляются по именам файлов; мусор в именах (`online-audio-converter`, номера, `_preview`) чистим.
- Картинки: №1 — обложка семпл-пака (плашка 9); №2 — фото с гитарой на карточки каверов (секция 10); №3 — audiojungle на карточки музыки для рекламы (секция 7).

## Структура

- Хук `useAudioTrack(src)`: состояние play/pause, текущее время, длительность, перемотка; глобально гарантирует один играющий трек.
- `TrackPlayer`: кнопка play/pause + прогресс + время. Используется в карточках секций 04, 07, 08, 10.
- Секция 09 использует тот же хук: существующая кнопка «Слухати» переключается в «Пауза», под ней полоса прогресса.
- Пути к mp3 учитывают basePath (деплой на GitHub Pages).
- Данные: массивы `{ number, title, src }` в секциях; файлы в `public/audio/<раздел>/`, картинки в `public/images/`.

## Адаптив

Плеер тянется на ширину карточки; на мобильных кнопка и полоса не меньше 40px по высоте касания. Картинка в карточке — квадрат в правом верхнем углу (как в карточках аранжувань), размер от ширины карточки.

## Поведение

- Клик по play: трек играет, иконка → пауза. Повторный клик — пауза.
- Конец трека: возврат в начало, иконка play.
- Ошибка загрузки: кнопка остаётся, воспроизведение не стартует (без сообщений).
- Клавиатура: кнопка и ползунок фокусируются, у ползунка aria-label.
- «Процес роботи» остаётся заглушкой.

## Риски

- Вес `public/audio` ≈ 69 МБ; для GitHub Pages допустимо, но репозиторий вырастет.
- Safari требует жеста пользователя для play — запускаем только по клику.
- Тесты: jsdom не реализует `HTMLMediaElement.play/pause` — мокаем.
