# 02 — About («Вітаю!»): анализ

Статус: утверждён
Figma: node `2001:20` (`1:92`, `1:96`, `1:97`, `1:107`, `1:84`, `1:94`, `1:90`, `1:80`, `1:98`), фрейм `1:2`, y 900–1846

## Цель

Блок знакомства: круглое фото слева, приветствие и рассказ о себе справа, на фоне огромное слово `Denis` и наклонные линии.

## Дизайн

- Холст 1600 × 946 (от y=900 до начала секции обложек на y=1846), фон `#171717`.
- Слева круглое фото 525px (`imgImage`, 1050×1050) с тёмным кольцом 547px (`imgEllipse4`) и оранжевым полумесяцем 515px (`imgEllipse3`) за ним. Блок 615 × 606 с отступом слева 70.
- Огромное `Denis` (ExtraBold 200px, цвет фона `#171717`, едва заметный контур), частично за фото.
- Справа колонка с левым краем 793 и шириной ~518: `Вітаю!` (Bold 30px), `Мене звати Денис Булах!` (Medium 20px), абзац 1 (Medium 20px), абзац 2 (Medium 20px, сохраняются двойные пробелы). Все белые.
- Справа внизу восемь наклонных линий (`imgGroup6.svg`, 1592 × 888, слева 849, сверху 306), обрезаются границей секции.
- Тексты дословно из Figma, без хвостовых пробелов:
  - «Вітаю!»
  - «Мене звати Денис Булах!»
  - «Мені 23 роки. Я гітарист, музикант! Прагну працювати в сфері аранжування і звукозапису з вами!»
  - «Я маю досвід роботи на студії в онлайн форматі вже 4 роки.  Ось деякі треки на які я прописував гітарні партії і аранжування та докази, що робив їх саме я:»

## Структура

- Компонент `src/components/sections/About.tsx`, секция `id="about"`, без контейнера, внутри обёртка с обрезкой.
- Сцена в контейнерном запросе: единица `--u = 100cqw / 1600` на десктопе, позиции блоков задаются числами макета.
- Заголовок «Вітаю!» — `h2`; `Denis` и фото — декор (`aria-hidden`, `alt=""`).

## Адаптив

- Desktop (≥1024): абсолютная раскладка макета, масштабируется по ширине (max 1600). Шрифты масштабируются, но не меньше 14px для текста.
- Tablet / mobile (<1024): одна колонка: сверху фото (до 420px, по центру), ниже текст, `Denis` бледным фоном над заголовком, линии уменьшены и прижаты к правому нижнему углу. Отступы по бокам как у контейнера страницы.

## Поведение

Статичный блок, интерактива нет.

## Риски и edge cases

- Двойной пробел в абзаце 2 сохраняется (`white-space: pre-wrap`).
- Линии выходят за секцию: нужна обрезка.
- На узких экранах длинные слова не должны вызывать горизонтальный скролл.

## Критерии готовности

- [ ] Визуально совпадает с Figma на 1600.
- [ ] Нет горизонтального скролла на 320–2560.
- [ ] Тесты: тексты дословно, h2, декор скрыт, alt пустые, нет внешних ссылок.
