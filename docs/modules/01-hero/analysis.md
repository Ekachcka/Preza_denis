# 01 — Hero: анализ

Статус: утверждён
Figma: node `1:23`, `1:78`, `1:27`, `1:28`, `1:26`, `1:9` (фрейм `1:2`, верхняя часть, y 0–900)

## Цель

Первый экран портфолио: имя, слово PORTFOLIO, три круга с фото и огромные буквы-декор на фоне, поверх наклонные золотистые линии.

## Дизайн

- Холст 1600 × 900, фон `#171717`.
- Огромные буквы цветом фона `#171717` (видны только по тонкому контуру): `Denis` (ExtraBold 200px), `Bulakh` (ExtraBold 200px), `P` (Black 500px), `o` (Black 600px). Контур на `P` и `o` белый, на `Denis` и `Bulakh` едва заметный. Контур есть на скриншоте, в коде Figma его нет.
- Восемь наклонных линий (углы 8.6°–9.5°), выходят за пределы кадра, обрезаются секцией.
- Три круга диаметром 495px: оранжевый (`#ffa028`, `imgEllipse1`), чёрно-белое концертное фото (`imgImage4`) и портрет с гитарой (`imgImage3`). Концертное и портретное фото в тёмном кольце 514px (`imgEllipse2`).
- Тексты: `Bulakh Denis` (Regular 30px, в оранжевом круге, перенос по ширине 164px), стрелка (`imgGroup2`), `Guitar is my voice, music is my story.` (SemiBold 15px, ширина 148px), `PORTFOLIO` (Bold 70px, capitalize, белый, поверх фото).
- Ассеты: `imgVector4…imgVector11.svg` (линии), `imgEllipse1/2.svg`, `imgImage4.png` (1280×854), `imgImage3.png` (JPEG 4096×2822, тяжёлый), `imgGroup2.svg`.

## Структура

- Компонент `src/components/sections/Hero.tsx`, секция `id="hero"`, без контейнера, внутри обёртка с обрезкой.
- Одна разметка на все ширины. Сцена лежит в контейнерном запросе (`cqw`), все размеры задаются через единицу `--u` (на десктопе `100cqw / 1600`, на мобильном `100cqw / 390`), значения позиций пишутся числами макета.
- Линии: массив данных (позиция, поворот, размеры, файл) в `src/components/sections/hero/decorLines.ts`.
- Буквы и декор — `aria-hidden`; `h1` — «Bulakh Denis».

## Адаптив

- Desktop (≥1024): сцена масштабируется пропорционально ширине, максимум 1600, по центру; при 1280–1600 совпадает с макетом.
- Mobile / tablet (<1024): перекомпоновка, сцена max-width 640px: буквы и круги в `cqw`, круги каскадом, `PORTFOLIO` по центру над средним кругом, линии уменьшены (масштаб `100cqw / 700`).
- Горизонтального скролла нет: секция обрезает всё лишнее.

## Поведение

Статичная секция, интерактива нет. Фото декоративные, `alt=""`.

## Риски и edge cases

- Тяжёлые фото только через `next/image` с `sizes`.
- Контур букв и кольца — по скриншоту, не по коду Figma.
- На очень узких экранах (320) буквы мелкие, но не выходят за экран.

## Критерии готовности

- [ ] Визуально совпадает с Figma на 1600.
- [ ] Нет горизонтального скролла на 320–2560.
- [ ] Тесты: заголовок, тексты, декоративные картинки с пустым alt, отсутствие внешних URL, `aria-hidden` у декора.

## Открытые вопросы

Нет (решения приняты лидом: lang uk, hover минимальный, фото декоративные).
