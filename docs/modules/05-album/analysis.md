# 05 — Альбом Кукушкіна: анализ

Статус: утверждён
Figma: фрейм `1:2`, node `2001:11`

## Цель

Показать большую карточку альбома Kostiantyn Kukushkin Accordion и семь карточек треков с кнопками «Процес роботи».

## Дизайн

Большая карточка #414141, скругление 27, обложка с оранжевой рамкой, заголовок 50px Medium оранжевым, подпись «Album "Any price"» 30px, оранжевая линия. Треки: Any Price, Libertango, Promenade (ряд из 3), Now or never, Night, TIME, Winter (ряд из 4); номера 01–07 оранжевые, названия 45px SemiBold белые.

## Структура

Компонент секции Album, данные треков массивом; кнопки через ProcessButton.

## Адаптив

- Десктоп (≥1280): композиция макета 1600.
- Планшет: верхний ряд 3 колонки, нижний 2; карточка альбома в строку.
- Мобильный: верхний ряд 1 колонка, нижний 2; карточка альбома столбцом.

## Поведение

Кнопки и карточки без ссылок (заглушки по решению проекта). Минимальный hover (прозрачность) и focus-visible кольцо.

## Риски и edge cases

- Макет на абсолютных позициях, переводится во flex/grid.
- Горизонтального скролла нет на 320–2560.

## Критерии готовности

- [ ] Визуально совпадает с Figma на 1600.
- [ ] Нет горизонтального скролла на 320–2560.
- [ ] Unit-тесты на рендер и тексты.

## Открытые вопросы

Нет: решения по адаптиву, hover/focus и alt приняты пользователем.
