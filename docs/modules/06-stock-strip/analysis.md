# 06 — Плашка стоковой музыки: анализ

Статус: утверждён
Figma: фрейм `1:2`, node `2001:12`, fileKey `FIGMA_FILE_KEY`

## Цель

Плашка с круглым фото и текстом о стоковой музыке.

## Дизайн

Тёмная плашка #0b0b0b на всю ширину, круглое фото 193px с оранжевой рамкой, текст 30px Medium белый в четыре строки.

## Структура

Секция StockStrip на общем компоненте ProfileStrip (фото, текст, необязательный слот действия).

## Адаптив

- Десктоп (≥1280): композиция макета 1600.
- Планшет: как десктоп, уменьшенные размеры.
- Мобильный: фото сверху, текст по центру.

## Поведение

Кнопки и карточки без ссылок (заглушки по решению проекта). Минимальный hover (прозрачность) и focus-visible кольцо.

## Риски и edge cases

- Макет на абсолютных позициях, переводится во flex/grid.
- Горизонтального скролла нет на 320–2560.

## Критерии готовности

- [ ] Визуально совпадает с Figma на 1600.
- [ ] Нет горизонтального скролла на 320–2560.
- [ ] Unit-тесты на рендер и тексты.

## Открытые вопросы

Нет: решения по адаптиву, hover/focus и alt приняты пользователем.
