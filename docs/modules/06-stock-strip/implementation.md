# 06 — Плашка стоковой музыки: реализация

Статус: готово

## Что сделано

Тёмная плашка на всю ширину: круглое фото слева и текст о стоковой музыке справа («Я писав стокову музику в різних стилях таких як Corporate, Funk, Pop, Disco, Cinematic, Rock, Lo-Fi. Також трохи писав аудіо логотипи (Logo)»).

## Поведение

- Статичная, без интерактива.
- На мобильном фото сверху, текст по центру.
- Плашка использует общий компонент для секций с фото и текстом, у которого есть необязательное место под действие (используется в плашке семплов).

## Проверка

Typecheck, lint, unit проходят; визуально сверено на 1600; горизонтального скролла нет.
